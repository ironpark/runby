# runby 문서

이 디렉터리는 두 종류의 문서를 분리해서 담습니다.

| 디렉터리 | 대상 독자 | 내용 |
|---|---|---|
| (루트 [`README.md`](../README.md)) | 처음 온 사람 | 설치, 5분 안에 쓰기 위한 최소한 |
| [`guide/`](guide/) | 라이브러리 사용자 | 축별 상세와 API 레퍼런스 |
| [`research/`](research/) | 이 저장소 관리자 | 각 제품의 환경변수를 공식 문서·소스에서 확인한 조사 기록 |

## 왜 나누는가

`research/`의 문서는 사용법이 아니라 **근거**입니다. 이 라이브러리가 하는 판정은 전부 "이 환경변수가 이 제품이 실행한 프로세스에만 설정되는가"라는 질문의 답이고, 그 답은 제품의 공식 문서와 소스에서만 나옵니다. 조사 문서는 그 확인 과정, 확인하지 못한 것, 그리고 확인 결과 **감지하지 않기로 한 제품과 그 이유**까지 기록합니다.

따라서 이 문서들은 코드와 함께 유지보수됩니다. 제품이 환경변수 계약을 바꾸면 코드보다 먼저 조사 문서가 바뀌어야 합니다. `TestSlugsMatchDocs`는 `runby`가 보고하는 모든 식별자에 대응하는 조사 문서가 존재하고 `slug`가 일치하는지 검사하므로, 문서 없이 제품을 추가할 수 없습니다.
